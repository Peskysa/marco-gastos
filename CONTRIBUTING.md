# Contribuir

Abre incidencias en el repositorio público con pasos reproducibles y datos inventados. Para cambios, crea una rama y ejecuta las pruebas de lógica y navegador. Mantén el idioma español, el cálculo en céntimos enteros, la privacidad local y las cinco modalidades. No cambies el formato de copias sin migración y pruebas. Las contribuciones originales se distribuyen bajo AGPL-3.0-only; conserva avisos de terceros.
