# Capturas reales

Generadas al ejecutar la aplicación con Playwright, con datos ficticios explícitamente marcados como ejemplo.

- images/escritorio.png: resumen mensual, reparto por categorías y presupuestos.
- images/funcion.png: formulario real de registro de un movimiento.
- images/movil.png: interfaz a 390 × 844 píxeles.

No representan prueba en teléfono físico. Se regeneran con `pnpm test:browser`.
