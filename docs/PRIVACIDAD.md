# Privacidad

Marco Gastos no solicita cuentas, no conecta bancos y no incorpora anuncios, analítica ni servidores de movimientos. Los datos se guardan en localStorage del perfil de navegador o WebView; Electron usa un perfil local. No hay sincronización automática.

El alojamiento web GitHub Pages recibe las solicitudes normales necesarias para servir recursos y puede registrar metadatos técnicos conforme a sus políticas. La aplicación no incluye importes ni conceptos en URLs, peticiones o estadísticas. El enlace al repositorio abre GitHub solo por acción del usuario.

Los datos y las copias JSON/CSV se conservan sin cifrado propio. La protección depende del dispositivo, sus usuarios y el navegador. No uses datos sensibles en equipos compartidos ni envíes copias a incidencias públicas. Borrar almacenamiento, desinstalar, perder un perfil o usar navegación privada puede perder datos. Exporta copias periódicas y protégelas.

Vaciar datos elimina los registros de la aplicación con confirmación; el último estado sigue disponible para Deshacer durante la sesión, y el navegador/sistema puede mantener sus propios restos o copias. No se promete borrado forense. Los archivos exportados se borran por separado.

Android no solicita permiso INTERNET ni acceso global a archivos. Guardar y restaurar usan documentos elegidos por el usuario. Web Portable escucha solo en 127.0.0.1:5197 y sirve recursos de solo lectura; los movimientos permanecen en el navegador.
